Why trust it?

On camera, every time

The agent runs in an isolated VM with its screen streamed continuously. Nobody touches the keyboard during a sweep. If the stream drops, sweeps pause.

A reserve for tax, nothing else

Creator fees are income to us, so a 20% reserve covers the tax on them. Everything after the reserve goes where the holder pointed it. We don’t take a cut.

Read the method

Sweep math, on the stream

Every weight, reserve and donation is computed out loud by the agent before it pays. The log is in every recording.

Card redacted, receipt shown

The card number is blacked out in post. Nothing else is touched. GoFundMe’s confirmation stays in frame.

Disputes resolved in public

Raise one on X or by email. It is logged with the sweep it concerns and corrected in the next one.

Open data feed

The agent writes a JSON file after every sweep. The site reads it; so can you.
